# B7 第一步：Logo 与字模素材读回检查

本步准备静态 OSD 使用的样例素材，尚未实现视频叠加。B6 交付包复跑 `delivery/B6_review_20261005_231335/build/video_modes_buttons_sim/run_20261005_231903_151402` 已核对通过；本步未修改此前图像/按键 RTL。

## 接口和位图语义

| 资产 | 输入 | 输出 | 规则 |
|---|---|---|---|
| anlogic_logo_rom | I_addr[14:0] | O_pixel[24:0] | 组合查表；地址 y×160+x；第 24 位为不透明位，其余为 RGB888 |
| osd_char_lib | I_char[7:0]、I_row[3:0] | O_row_bits[15:0] | 组合查表；16×16 字格；最高位是最左列 |

Logo 画布 160×160，共 25600 个位置，其中 6387 个位置不透明。ROM 未列出的地址默认输出 0；本测试读完全部 32768 个地址，包括画布以外地址。

字体含大写 A～Z、0～9、冒号、中文“安”和“路”，共 39 个字符；0x80/0x81 为两个中文字编码。其余编码（包含空格）输出空白。39 个字模具有相同 16×16 字格，但字形实际大小不同；例如 C 比一些大写字母高，保留样例原样，不宣称是一套等高字体。Logo 不透明边缘含浅色像素，在深色背景可能出现浅色边缘。

两个模块均无时钟、复位或 valid。它们只是查表资产，后续视频封装必须自行处理寄存器、有效区、透明区、裁剪、坐标及元数据延迟，不能把本步通过当成完整视频叠加通过。
