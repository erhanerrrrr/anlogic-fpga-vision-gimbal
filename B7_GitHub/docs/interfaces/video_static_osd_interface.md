# 独立静态 OSD 接口

## 输入输出与时序

接口沿用 RGB888 流：clk、低有效异步 rst_n，in_valid、in_rgb、in_x/in_y[10:0]、in_sof/in_eol/in_eof、in_source_frame_id[31:0]；增加本像素所属的 in_mode[1:0]。输出对应 out_*，包含 out_mode，全部与输出像素一起传递。

每上升沿接收一个有效像素，经两个寄存器级输出，吞吐仍为一拍一个像素，无反压。本模块不缓存行、不重排光栅、不增添尾行；在输入采样沿先进入第一级，下一上升沿更新最终输出，最后一像素也按此规则冲刷。所有显示字段与像素经历相同两级延迟。

复位异步清零全部输出和帧状态。复位后/EOF 后忽略没有有效 SOF 的片段，空白拍标记不触发帧开始；无效输出字段清零。已经输出的中断帧不能撤回，由下游丢弃。来源帧号只传递，不重新计数。

in_mode 是上游已经绑定到当前像素的模式标签，应在完整有效帧中保持一致。模块按它选择固定标签 RAW、GRAY、EDGE、MASK，不处理模式请求或按键，也不额外锁存 pending。接入时使用 `video_modes_buttons.out_mode`，不要接输入侧当前 requested_mode。若上游错误地在帧内改变标签，本模块不会替其修复。

## 布局、颜色与裁剪

默认 WIDTH=1280、HEIGHT=720；坐标接口支持 1～2048 尺寸，当前两级版本已验证 384×240 和 1280×720。ENABLE=0 完全直通（仍保留两级寄存器、元数据及复位规则）。布局参数均为非负整数，CROSS_HALF 默认 8；不支持负坐标布局。

| 元素 | 默认位置/尺寸 | 像素规则 |
|---|---|---|
| 安路 Logo | LOGO_X=0、LOGO_Y=0，160×160 | 原样例 25 位像素：第 24 位为不透明标志，RGB888 原样输出；透明位置保留下层 |
| 固定标题 | TITLE_X=168、TITLE_Y=16，160×16 | `FPGA VIDEO`；16×16 字格，文字 00E6FF，底条 17202B |
| 模式标签 | LABEL_X=168、LABEL_Y=48，160×16 | `MODE: RAW `、`MODE: GRAY`、`MODE: EDGE`、`MODE: MASK`；文字 FFF200，底条 17202B |
| 中心十字 | CROSS_X=WIDTH/2、CROSS_Y=HEIGHT/2 | FF00FF，水平/竖直各 17 像素，中心重合，总计 33 像素 |

坐标从左上角零开始，偶数分辨率中心按整数 WIDTH/2、HEIGHT/2 选取。优先级由低至高：输入背景 → Logo → 标题底条与字形 → 标签底条与字形 → 十字。标题和模式标签的整个矩形是叠加区；字形空白显示深色底条，不是透明。Logo 的透明区在没有其他元素覆盖时保持输入。

所有绘制与 0≤x<WIDTH、0≤y<HEIGHT 求交集，元素超出画面部分裁去。有效区以外坐标不绘制；合法视频契约仍要求有效输入坐标属于画面。十字在坐标零附近使用加法比较，避免无符号减法回绕。没有 alpha 混合、缩放或字体平滑。

原素材来自 [assets/osd/README.md](../../assets/osd/README.md)，字形大小和 Logo 浅色边缘保持不变。深色文字底条用于改善白色及灰阶背景的可读性，不改变字模。没有新增 ROM 初始化文件。
