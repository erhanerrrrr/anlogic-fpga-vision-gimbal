## 本次实际验证

2026-10-10，本机 Python 3.14.6，ModelSim Altera Starter 10.3c；H4E参考使用 NumPy2.5.3/SciPy1.18.1。机器已有 ModelSim，补充 SciPy 依赖后，以新的 ModelSim 适配入口运行原 H4E TB 与独立参考，无需先安装 Icarus。冻结 RTL/TB 未改动。

| 检查 | 本次结果 |
|---|---|
| H4E来源校验 | 216来源文件、64工程引用，已验收bit哈希一致 |
| H4E区域单测 | 68案例、2,506,752像素通过 |
| H4E完整链 | 13帧720p、11,980,800滤波像素、8,785,920显示检查像素、83,031 Logo像素通过 |
| 原B7 | 42运行源文件哈希通过；Logo/字体、5种静态OSD小图条件、3种整合显示条件通过 |
| 新B1a事件测试 | 734定向及固定种子向量，复位/中断/同拍/配置/颜色/ID回绕等通过 |
| 新B1a完整图像 | 9帧，8,294,400像素；每帧实际RTL与独立参考差异均为0 |
| 新B1a检查器负例 | 故意改错1个期望像素，检查器确实报错，未假通过 |
| 新B1a独立综合 | TD6.2.168116，暂定75MHz，setup+2.370ns、hold+1.047ns，TNS均为0 |

独立综合包含测试装载/观察包装：1058寄存器、3490 LUT、估计2852 Slice，0 ERAM、0 DSP、0锁存器。Logo已存在于H4E，集成时应替换对应功能，不能把本报告当纯新增资源直接加到整板。所有126个逻辑端口没有板级引脚约束的工具警告符合该独立包装用途，不代表可直接烧录。当前RTL哈希与最终仿真、综合一致。

H4E原始raw诊断实例有5个未连接输出（result_frame_id/result_cfg_id/target_id/cx/cy），ModelSim报告1条端口数警告加5条未连接输出警告。均为未使用的输出，不是缺失输入；冻结版本保留并在日志中记录。新 B1a 仿真无错误、无警告。

资源、时序及全部小型证据见 [本次报告目录](../reports/b1a_20261010/README.md)。本次综合针对独立观察包装，并不等于完整板级时序或资源增量；A整机接入后仍需重建与上板。
