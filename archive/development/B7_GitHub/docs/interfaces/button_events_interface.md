# 按键同步与去抖：独立模块验证

本步对应验收说明 B6 的独立按键部分，新增 `button_events.v`、`tb_button_events.v` 和 `check_button_events.py`。此前四模式链已通过小图、10 帧 720p 和独立 TD 检查；本步未修改这些图像模块。当前只验证按键事件，不代表已经实现真实按键切图或标定、跟踪功能。

## 接口

| 信号 | 含义 |
|---|---|
| clk / rst_n | 采样时钟 / 低有效异步复位 |
| buttons_async[2:0] | 三个原始按键电平，允许来自异步引脚 |
| pressed[2:0] | 去抖后的按住状态，1 表示按住，与引脚极性无关 |
| press_event[2:0] | 每次确认按下输出一拍 1，无长按自动重复 |

位 0/1/2 暂约定为模式、标定、跟踪启停事件，当前只输出事件，没有启动标定或移动设备。三个按键独立同步、独立计数，可同时产生事件。`ACTIVE_LOW=1` 默认低电平按下，设为 0 可选择高电平按下。实际板上引脚、上拉和极性尚未冻结。

原始电平归一为“1 表示按下”，先经过两级寄存器。与当前去抖状态不同的同步采样值连续出现 `DEBOUNCE_CYCLES=N` 次，才更新 pressed；中途回到旧状态则计数清零。确认按下产生一次 press_event，确认释放只重置按住状态。短暂释放不会重新允许第二次按下事件。

按下和释放都要满足 N 次稳定采样。计数器位宽为 `max(1,clog2(N))`，数到 N-1 提交，支持 N=1 和非二次幂阈值；参数须为正整数。RTL 默认 N=750000，每键 20 位计数器。若实际 clk=75 MHz，则该阈值约为 10 ms，外加同步级延迟；这是暂定示例，并非板级已验证配置。若 clk=50 MHz，10 ms 应为 N=500000。集成时按实际时钟与需要的去抖时间设置。

从原始变化第一次被时钟采到的边沿计为第 1 拍，连续稳定时在第 N+2 拍输出新状态和按下事件。同步器第二级输出更新后的值由下游下一采样沿使用。默认小图仿真 N=4，因此第 6 拍确认；这是数字流水的时序，不包括模拟亚稳态可能产生的额外不确定性。

复位异步清空同步状态、按住状态、事件及计数器，默认视为释放。旧的待确认按下不会在复位后继续计数；如果复位释放后物理按键仍按住，则重新经过同步和完整去抖后可视为一次新按下。复位释放在最终时钟域内的同步、同步器布局/约束和跨域事件传递仍需主工程处理。数字仿真不能证明模拟亚稳态不存在。
