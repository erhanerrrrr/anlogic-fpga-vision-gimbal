# 灰度算术练习

`rgb_to_gray.v` 把一个 RGB888 像素变成灰度 RGB888 像素，公式固定为：

```text
Y = (77*R + 150*G + 29*B + 128) >> 8
out_rgb = {Y, Y, Y}
```

输入颜色的高、中、低 8 位分别是 R、G、B。0 表示黑，255 表示白；绿色输入 (0,255,0) 按此公式得到 149。

模块与 `rgb_bypass` 的像素接口相同：`clk`、`rst_n`、`in_valid`、`in_rgb[23:0]`、`out_valid`、`out_rgb[23:0]`。低电平异步复位使输出全零；无效周期输出 RGB 为零。颜色运算为组合逻辑，颜色和 valid 一起经过一级输出寄存器，行内可每拍接收一个像素。

三项乘积及带舍入的总和都使用无符号 16 位数，总和最大 65408，输出取其高 8 位。不能把乘积或总和先压成 8 位，否则会溢出。这是行为实现，综合后的资源和可达频率需要另行验证。
