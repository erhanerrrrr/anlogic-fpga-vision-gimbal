# Sobel 算术核心：单独验证九宫格计算

用户承担图像处理 A，对应验收 ZIP 中按职责命名的 B4a。本文件记录单独给算术核心输入 3×3 灰度补丁的检查。后续已增加完整边缘流的小图集成、图片回放和两帧 720p 验证，见 `video_edge_interface.md`；B4b 的整链 TD 检查仍待完成。

## 输入输出与定点规则

`sobel_core.v` 输入为 `clk`、低有效异步复位 `rst_n`、`in_valid`、72 位 `in_window` 和 11 位无符号 `in_threshold`。窗口排列与 `window_3x3.v` 完全一致：高字节到低字节为 p00、p01、p02、p10、p11、p12、p20、p21、p22，每个像素为 8 位无符号灰度。

```text
p00 p01 p02
p10 p11 p12
p20 p21 p22

Gx = (p02 + 2*p12 + p22) - (p00 + 2*p10 + p20)
Gy = (p20 + 2*p21 + p22) - (p00 + 2*p01 + p02)
M  = abs(Gx) + abs(Gy)
edge = (M >= T) ? 255 : 0
```

左到右为 Gx 正方向，上到下为 Gy 正方向；中心 p11 的卷积权重为 0。每侧加权和最大 1020，使用 10 位无符号数；先补零扩展为 11 位有符号数再相减。`out_gx` 和 `out_gy` 为 11 位有符号数，范围覆盖 -1020～1020；`out_magnitude` 为 11 位无符号数。绝对值相加后保持足够位宽再比较阈值，不能先截为 8 位。

阈值范围为 0～2047，上游初始设置传入 `11'd128`。本核心没有隐含的阈值默认值，`in_threshold` 必须连接；测试的固定锚点、二值补丁使用 128，边界和随机用例另设阈值。阈值与窗口在同一个输入采样边沿使用，逐拍变化也能处理。若未来需要按键调整且整帧阈值一致，应由上游在帧边界锁存配置。

输出 `out_valid`、`out_gx`、`out_gy`、`out_magnitude`、`out_edge` 一起经过一级寄存器，能够每拍接收一个有效窗口。无效周期全部输出为零；复位立即清零，复位释放后可接收第一个有效补丁。本核心不含行缓存、SOF/EOL/EOF、坐标和帧号，也不自行丢弃半帧；视频接入层后续必须将这些字段同步延迟，并继承窗口层的帧接收规则。
