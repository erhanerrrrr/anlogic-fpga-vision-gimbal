# 完整边缘流：小图与 720p 集成验证

本步对应图像处理职责的 B4b 集成阶段。已连接 `video_gray → window_3x3 → sobel_core → edge_raster`，输入 RGB888，输出同尺寸黑白边缘图。已完成小图行为验证、实际 RTL 小图回放、整链连续两帧 720p 行为验证和整链 TD 独立综合检查；主工程集成及上板尚未完成。

## 接口与像素规则

`video_edge.v` 的输入、输出沿用现有单像素流：valid、RGB888、SOF/EOL/EOF、11 位 x/y、32 位来源帧号。上升沿采样，低有效异步复位。参数 WIDTH、HEIGHT 均为 3～2048，默认 16×12；参数 THRESHOLD 为 11 位无符号数，默认 128，在本版综合/仿真配置中固定，不提供帧中修改端口。

每有效周期输入一个像素，无反压。上游保证合法逐行光栅、行内连续有效、坐标和标记正确、帧内来源 ID 一致；行间/帧间空白可变，也支持无空白连续帧。本模块不修复损坏或缺行的输入序列。

灰度公式为 `(77*R+150*G+29*B+128)>>8`。内部窗口中心处使用已验证的 Sobel 算术和 `abs(Gx)+abs(Gy)>=THRESHOLD` 判断，输出白色 FFFFFF 或黑色 000000。第一/最后一行和第一/最后一列的最终输出强制为黑色；这是最终边界置零，不是对零填充图像做卷积。

每个完整输出帧仍有 WIDTH×HEIGHT 个像素，坐标从 (0,0) 到 (WIDTH-1,HEIGHT-1)。SOF、EOL、EOF 与首像素、行末和帧末像素对齐。来源帧号按该帧首个内部窗口行的 ID 保留，不重新编号。所有无效输出字段为零。

新增诊断输出 `out_error` 为复位清零的粘滞标志，发现行队列溢出、内部窗口行次序/ID 不匹配或内部像素协议异常时置位。正常测试要求它始终为 0；板级集成时应保留或汇总这一诊断，不能隐藏丢数据问题。

## 完整输出的调度

原窗口模块只输出内部中心。Sobel 后增加 `edge_raster.v`，使用四个循环行槽，每槽 WIDTH×1 位保存一行二值边缘，另存行号和来源 ID。收到该内部行的 EOL 后，才把整行加入可读队列；所有 8 位 Sobel 输出均为 0 或 255，因此只存一位即可恢复。

收到首个完整内部行后，先输出一行全黑顶边，再按顺序读取内部行。每个内部行输出左侧黑像素、WIDTH-2 个结果及右侧黑像素。最后再输出一行全黑底边。RAM 同步读取下一列，在输出左黑边的那一拍预取中心列 1，保证一行内每拍一个像素；队列暂时缺行时只在行间等待，不在行内打断。

已经读完的槽循环复用；不同帧可在流水中同时存在，行描述符和输出帧 ID 用于防止串帧。四槽在 720p 时只需 5120 个二值数据位，此外仍有窗口层两行 8 位灰度缓存。5120 位是 RTL 逻辑存储量；TD 实际将四槽映射到一块 ERAM20K，两行灰度另用两块。存储数组不做整体复位，读写指针、队列计数及有效状态控制旧数据的有效性。

输出具备完整逐行有效光栅，但行间空白可能不同于输入，也未提供 HDMI HS/VS 时序。最终显示适配还需依据真实显示时钟和有效区调度进行验证，不能直接把当前 out_valid 当作已经验证的 HDMI DE。

## 延迟、帧尾与复位

| 环节 | 输入采样边沿到对应结果 |
|---|---|
| 灰度 | 一级输出寄存器 |
| 窗口 | 两级寄存器，并等待窗口历史；中心相对输入为 (x-1,y-1) |
| Sobel | 一级输出寄存器；坐标、EOL、ID 在并行寄存器中同拍延迟 |
| 行槽写入 | 再一拍写入二值结果；EOL 同拍提交完整行 |
| 光栅输出 | 首行提交后下一拍开始输出黑色顶边，再连续输出/按行等待 |

无空白输入时，从输入 SOF 采样边沿到输出 SOF 更新边沿相差 `3*WIDTH+4` 个时钟周期。若输入前两行之后分别有 B0、B1 拍空白，则首像素延迟增加 B0+B1。后续像素不是简单的固定拍延迟，因为输出会重新安排行间空白；这一点必须在以后做原图/灰度/边缘模式对齐时处理。

默认小图第一、第二帧的输入空白配置不同，测得 SOF 延迟分别为 55、57 周期；EOF 延迟均为 36 周期。无空白 16×12 用例的 SOF 延迟为 52 周期。仿真时钟为 10 ns，仅用于行为测试，不表示整链硬件已在 100 MHz 工作。

最后一个输入像素之后不需继续补像素，保持时钟即可输出剩余行和底边。测试采用 `6*WIDTH+16` 周期作为每个输入 EOF 到对应输出 EOF 的保守上限，并逐帧检查；超时会失败。此上限只用于约定的合法光栅输入，不接受缺失行/EOF 后无限等待为成功。

复位立即清空输出、流水有效状态及行槽计数，灰度入口重新等待有效 SOF。旧帧尾部被忽略，新帧重新建立两行历史。已输出的半帧前缀无法撤回，下游须丢弃未以 EOF 完成的帧。默认测试在已经输出 24 个前缀像素后复位，丢弃旧帧尾部，随后验证两帧完整图片。
