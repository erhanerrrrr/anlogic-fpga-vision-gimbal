# 带帧信息的灰度流

`video_gray.v` 使用与 `video_bypass.v` 相同的单像素 RGB888 输入、坐标、标记及来源帧号接口。输出 RGB 变为 `{Y,Y,Y}`，公式沿用已验证的 `rgb_to_gray.v`。

灰度运算调用 `rgb_to_gray`；坐标、SOF/EOL/EOF 和来源帧号在同一个上升沿进入各自的寄存器。两部分并行，因此整层仍然只有一级寄存器延迟，每拍可接收一个有效像素。这里没有在 `video_bypass` 后额外串接一级灰度模块。

复位和帧接收规则与直通层相同：低电平异步复位，输出全零；等待有效 SOF 后接收像素，EOF 关闭当前帧。无效输入和无 SOF 的碎片不会输出。坐标和帧号由上游提供并原样传递，模块不自行编号。

运行方法见[仓库首页](../../README.md)，本阶段证据见[验证说明](../validation.md)。
