# B1b 字体统一修正验收记录

原字库混合了小号字母和较大的数字/部分字母，导致同一行视觉尺寸不同。B1b改为5×7字形放大2倍，数字及大写字母统一14像素高，字符格仍为16×16；标点和自然窄字保留正常字形。
