# B2b 本机自动验证记录（2026-10-12）

运行与接口见 ../../B2b_README.md。本阶段提供共享一拍控制信号的RAW/GRAY两路候选输出；模式选择留待B2d/B3。自动验证通过，使用者已于2026-10-14复跑通过并确认原图/灰度图片正确。没有板测或新bit。

- 独立灰度级：5853向量（5280个有效颜色），灰阶/三原色遍历、随机色、舍入边界、插空、复位及abort通过。
- 真实C配对联合：3×3零消隐、16×12零消隐、16×12带消隐各6帧；720p 1650×750光栅6帧，5,529,600像素RAW/GRAY/mask/metadata全部零差异。
- 小图覆盖跨帧尾部与下一帧重叠；720p FIFO峰值1284，深度2048，正常场景全部错误标志为0。
- 12个小图故障/恢复场景、1个容量不足场景、1个720p帧中复位场景通过；720p恢复后完整921600像素RAW/GRAY/mask核对通过。
- 故意破坏期望mask，检查器确实失败，见negative_checker.log；该文件内错误是预期自测。
- 延迟：比B2a统一增加1拍；首像素距输入SOF1655拍，输出EOF距输入EOF1285拍。逐行事件见native_720p/timing.csv。
- 所有提交RTL的哈希与最终仿真、综合吻合。B1a清单47份、B1b字体版25份、B2a清单16份文件保持原哈希。

TD6.2.168116，PH1P35MDG324 -3，75MHz暂定约束；setup+2.847ns、hold+0.457ns、TNS=0。ERAM仍为RGB FIFO 3块和C滤波行缓存2块。灰度使用保持77/150/29及加128舍入的移位加法，原B7模块未改动。

唯一综合警告是独立包装123个逻辑端口没有板级LOC约束。此处未验证完整板级时序/引脚/CDC；资源不是整板净增量。没有新增图像缓存、重复C实例或灰度到彩色检测的反馈。

actual_raw_gray_overview.png来自实际RTL输出缩略图；native_720p内保留色块、复杂彩色、灰阶三组实际/参考/差分图片。大型逐像素输出、mem、波形仅在build，可用脚本重新生成，不上传。

A接入时复用一份C分类/滤波与RGB配对，将RAW/GRAY作为同拍候选；继续负责最终HDMI供数及真实DDR来源绑定。B2b输出不是原生HDMI时序。OSD、EDGE、四模式及按键联合验收不在本报告范围。
