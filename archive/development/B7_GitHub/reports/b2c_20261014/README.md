## 独立综合

TD 6.2.168116，PH1P35MDG324 -3，暂定 75 MHz，含观测包装：1719 寄存器、1754 LUT、估计 1382 Slice、7 ERAM、0 DSP、0 锁存器。

相对 B2b 增加 830 寄存器、877 LUT、估计 651 Slice、2 ERAM。ERAM 分配：原 RGB 队列 3、C 滤波 2、灰度窗口 2；没有第二份 RGB 队列或整帧缓存。setup/hold 余量为 +2.826/+0.292 ns，TNS 均为 0。唯一综合警告是独立包装 124 个端口未设置板级 LOC。

## 证据位置及边界

- `stream/`：所有画面用例、源哈希、仿真日志、事件时序和负例日志。
- `stage/`：算术和独立边缘级故障验证。
- `faults/`：真实 C 联合链故障和 720p 复位恢复。
- `synthesis/`：资源、RAM 映射、约束、时序和工具日志。
- `images/`：色条、绿块、复杂彩色三个场景的实际图、EDGE 参考和联合差分。原图保留 1280×720；总览采用 BOX 缩小，细边会变暗，以原图为准。
- `delivery_manifest.json`：当前交付源码哈希和用户验收状态；大 mem、像素二进制和工具库仅留在 build。

当前 base_* 与 EDGE out_* 输出时间不同，B2d 需统一四模式的时序后再切换。测试身份为合成标签，不证明真实采集/DDR来源。尚未完成完整板级时序、bit 或板测。接口和复跑命令见 ../../B2c_README.md。
