# C2：逐帧颜色掩膜

2026-10-05；接口 c2-draft-1。独立模块仿真、TD 早期综合通过；公共接口仍待 A/B 确认，未做上板或团队集成验收。

## 本步实现

把 C1 分类器接到像素流中。属于指定颜色的像素输出 1，其他像素输出 0；输出坐标、帧号、SOF/EOL/EOF 与 mask/valid 同时寄存。没有去噪、面积、框或中心计算。

每有效拍接收一个 RGB888 像素，无反压。点运算延迟为一个输出寄存级，没有新增整行/整帧缓存。输入在上升沿稳定，输出在该边沿寄存更新后可见，下游在下一上升沿采样。最后像素与 EOF 同时输出，不需要额外冲刷。

## 给 A/B 的接口

RTL：rtl/recognition/color_mask_stream.v；源文件列表：rtl/recognition/c2_sources.f。

| 输入 | 语义 |
|---|---|
| clk、rst_n | 上升沿采样；低有效异步清零，实际集成同步释放 |
| pixel_valid、rgb[23:0] | 一拍一个像素，R 在最高 8 位 |
| active_color[1:0] | 0 红、1 绿、2 蓝；3 对有效像素输出黑色 |
| x、y | 默认各 11 位，左上角 (0,0)，逐行顺序 |
| sof、eol、eof | 分别与首像素、行末像素、帧末像素同拍 |
| source_frame_id | 默认 32 位，透传；不做新旧大小比较 |

输出：mask_valid、mask、mask_x、mask_y、mask_sof、mask_eol、mask_eof、mask_frame_id。B 在 mask_valid=1 时将 mask 映射为 0→黑、1→白，并使用对应输出坐标与标记。B 负责与其他显示分支及物理显示时序对齐。

MIN_MAIN/MIN_DIFF_1/MIN_DIFF_2 是 C1 同样的编译期常量，默认 80/40/40。参数位宽为 8 位，内部差值为 9 位有符号数。

active_color 在整帧期间必须固定。本模块接收已生效的配置，不直接处理按键请求，不提供帧边界配置状态机。跨时钟转换由 A 实现。当前仅支持合法逐行输入，未实现错误坐标或错误 EOF 的自动检测。

## 空白与复位

- 行内连续有效，行间/帧间可有空白；空白不产生有效输出，输出字段均清 0。
- 启动或帧中复位后，丢弃直到下一次有效 SOF 之前的像素。
- 一帧 EOF 之后，直到下次有效 SOF 前的额外像素不输出。
- 复位前已经输出的半帧不能撤回；下游必须共享复位并丢弃半帧，不能将它标为完整帧。
- 本模块不发布目标结果。即使 source_frame_id 重复，仍可生成显示掩膜；新观测去重到 C7 实现。

## 一键运行

```powershell
python scripts/run_c2.py
python scripts/run_c2_td.py
```

需要 Python 3.7+、ModelSim vlib/vlog/vsim；综合另需 TD 命令行工具。均无第三方 Python 包依赖。脚本使用临时目录，不依赖本机绝对路径；综合不改厂家工程、不执行下载。

ModelSim 单进程外部超时 300 秒，testbench 最大模拟时间 100ms。必须运行到完成标记且所有输出完整一致，否则失败并返回非零。TD 超时 180 秒，并检查退出码、完成标记和实际报告/网表存在。

已产生的仿真结果可用 `python scripts/run_c2.py --check-only` 重新比较，无需再运行仿真。`python scripts/run_c2.py --check-only --inject-error` 故意改坏首个期望像素，必须退出 1。

## 用例和独立答案

固定配置：tests/fixtures/c2/cases.json；参考使用 Python 整数分类规则和独立图案生成，绝不从 RTL 输出推导期望。

1. 640×360 红矩形 x=100..140、y=80..110：恰好 1271 个 1。
2. 下一帧同位置换绿色，红规则下全 0，确认不残留上一帧。
3. 红绿蓝黑白灰色条，分别选择红/绿/蓝，检查完整掩膜。
4. 贴左上边界的红色 9×7 矩形，63 个 1，不裁边（此时还没有去噪）。
5. 固定种子 20261005 的确定性噪声图，逐像素比较。
6. 帧中在第 135 个像素前复位：前缀单独计为半帧；后续帧尾不输出，不产生 EOF；下一完整帧正常恢复。
7. 连续两帧 1280×720：一帧噪声、一帧全绿，各 921600 个有效掩膜像素；帧号从 0xffffffff 回绕到 0，均原样透传。
8. 初始残余帧尾无 SOF、停输入保持时钟、行间 1～4 拍空白及不同帧间空白。

共 10 个完整帧加 1 个被复位中断的帧前缀；实际输出 2322567 个像素。仿真逐拍检查 metadata/valid、输出保持、异步复位和 X/Z；Python 再对实际导出的每个像素检查 mask、坐标、帧号和标记。

## 综合检查及限制

本机 TD V6.2.168116，使用厂家例程器件 PH1P35MDG324、脚本速度参数 3。门级优化报告 105 LUT、60 寄存器、0 RAM、0 DSP；分类器逻辑和输出寄存器确实保留，没有综合成常量空壳。

唯一关键告警为 145 个逻辑端口没有物理引脚约束。这里把内部模块临时作为顶层做综合，它的内部总线被统计为顶层 IO；不代表最终系统额外占用 145 个引脚。集成后应由 A 的整机顶层约束真实板级 IO。

未布局布线，未冻结像素时钟，未做完整时序约束或频率验收；这里的资源数字也不是最终布局资源。没有实物色卡测试，默认阈值仍为仿真基准。
