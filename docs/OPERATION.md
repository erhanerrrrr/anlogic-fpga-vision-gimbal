# 板端操作

## 启动与跟踪

默认显示实时画面、安路 Logo、紫色中心标记及识别框，文字信息面板隐藏。SW1 许可后，松开 K4，再长按约 1 秒启用跟踪；追踪中按 K4 或撤销 SW1 停止。SW1 重新许可不会自行启动。

当前水平 PWM 范围为 1000–2000 μs，俯仰范围为 1200–1800 μs，中位为 1500 μs。脉宽表示输出命令，不能直接当作实测机械角度。停止输出 PWM 后，俯仰机构需要自身支撑。

SW1 禁止且处于 OFF 状态时，短按 K4 切换：详细页 → 精简页 → 演示叠加页 → 延迟页 → 详细页。默认处于演示叠加页。

## 按键与页面

| 页面/模式 | K1 | K2 | K3 |
| --- | --- | --- | --- |
| 普通图像模式 | 切换图像模式 | 选择红/绿/蓝目标 | 中央区域颜色标定 |
| MOTION | 切换图像模式 | 保留颜色选择 | 采集空背景 |
| SENSOR AE | 切换图像模式 | AUTO112 / AUTO96 / AUTO128 / FIXED | 锁定或恢复曝光调节 |
| 延迟页 | 暂停/恢复统计 | 切换图表刻度 | 清零统计 |

八种图像模式依次为原始画面、灰度显示、二值化、边缘提取、颜色掩模、色阶简化、运动检测、传感器自动曝光。

## 运动检测与外设

保持摄像头不动，清空观察区域，按 K3 采集背景，等待 BACKGROUND CLEAR。物体进入后显示黄色前景框，移动时为 MOVING，停止后为 PRESENT STILL；移走后清框。较大的场景变化或背景失效时，应清空视野重新采集。

数码管与双色灯共用引脚，需要将 SW2 软件选择与 SW6 的硬件供电选择配套切换。

| 状态 | 双色灯 | 数码管状态码 |
| --- | --- | --- |
| 空背景 | 1 颗绿灯 | 2 |
| 运动前景 | 8 颗红灯 | 3 |
| 静止前景 | 4 颗红灯 | 4 |

MOTION 数码管左四位显示前景网格数，最多显示 4095；右四位显示状态码。其他码：0 待背景，1 采背景，5 场景变化，6 无视频，7 等待稳定。

蜂鸣器通过 SW5 硬件开关控制。MOTION 从无前景变为有前景时短鸣一次；标定/背景采集反馈也使用事件提示。普通跟踪模式下，目标或视频有效状态丢失时有提示，不持续重复鸣叫。

普通模式的数码管详细页显示水平/俯仰命令脉宽，其余页显示目标坐标；坐标失效时显示横杠。双色灯在普通跟踪模式下表示各轴目标偏差方向及等级。

## 自动曝光与延迟

SENSOR AE 调节 SC500CS 的曝光时间和模拟增益。改变光照后可观察参数、画面与状态变化；DARK LIMIT/HIGHLIGHT LIMIT 表示达到调节限值或进入高光保护，不等于功能故障。

MOTION 背景采集和颜色标定会等待曝光稳定并冻结相关参数。若显示 I2C ERROR RESET，应先检查摄像头连接和供电，再重新配置同一 bit。当前没有接入独立系统复位按键，网口旁红色按钮是电源开关。

延迟页显示当前、最小、最大延迟，附趋势、样本数与重复/无效帧统计。暂停统计时，实时视频继续显示。

## 可选串口记录

UART 为单向 TX，115200 baud、8N1。安装 `tools/requirements.txt` 中的 pyserial 后，可手动指定串口：

```powershell
python tools/telemetry.py --port COM5 --seconds 60 --output recording.csv
```

串口号按实际设备修改。该脚本接收遥测，不向 FPGA 发送控制命令；离线解码不依赖 pyserial。UART 的内部数据年龄字段与 HDMI 延迟页使用的完整视频链路延迟是不同指标。

## 下载文件

已有配置文件为 `release/F3A_demo_overlay.bit`，器件选择 PH1P35MDG324。可先使用 PROGRAM_SRAM 验证；源码整理和脚本运行不会自动连接下载器、串口或写入 Flash。背景和颜色标定保存在运行时寄存器/存储器中，重新配置后需要重新设置。
