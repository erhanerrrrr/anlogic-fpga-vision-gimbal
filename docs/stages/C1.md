# C1：单像素红绿蓝分类

日期：2026-10-05。状态：独立 RTL 仿真通过；公共 S0 接口与 A/B 交叉验收仍待确认，本模块尚未作为团队集成基线。

## 做了什么

输入一个 RGB 像素和当前选定颜色，输出该像素是否属于目标颜色。默认规则：主通道至少 80，且比另两个通道分别至少高 40。

| 颜色编码 | 主通道 | other_1 | other_2 |
|---|---|---|---|
| 0 红 | R | G | B |
| 1 绿 | G | R | B |
| 2 蓝 | B | R | G |
| 3 非法 | 不分类，mask=0 | — | — |

`active_color` 是已经选好的同步配置，不是原始按键请求。非法编码只令此像素 mask=0；S0 草案中“非法请求保持原颜色”的行为属于上游配置管理器。本阶段未实现按键、帧边界切换、标定或整帧统计。测试中按像素改变颜色只用于隔离验证分类核；正式接入必须由上游保证整帧配置固定。

## 接口 c1-draft-1

- `clk`：上升沿；`rst_n`：低有效异步清零，实际集成需同步释放。
- `pixel_valid`：当前像素有效；`rgb[23:0]`：R[23:16]、G[15:8]、B[7:0]。
- `active_color[1:0]`：同步当前颜色。
- `mask_valid`、`mask`：同时经过一个输出寄存器；输入在采样边沿稳定，输出在该边沿寄存更新后可见，下游在下一边沿采样。无额外多周期计算，每拍可接收一个像素，无反压。
- 无效输入拍的两个输出均为 0；复位时也均为 0。非法颜色且输入有效时 mask_valid=1、mask=0，仍保留像素的位置语义。
- 参数 MIN_MAIN/MIN_DIFF_1/MIN_DIFF_2 均为 8 位无符号常量，范围 0～255，在编译展开时设定。运行时标定留到 C9。
- 差值先把通道扩成 9 位有符号数再相减，范围 -255～255；阈值也扩成正的 9 位有符号数，避免无符号下溢。

该点运算核不携带坐标、帧号和 SOF/EOL/EOF，C2 必须将它们随同一个寄存级对齐。半帧复位后等下一 SOF 恢复属于 C2 帧封装责任，本核只清空当前输出。

## 如何运行与查看

在项目目录执行：

```powershell
python scripts/run_c1.py
```

需要 Python 3.7+，ModelSim 的 vlib/vlog/vsim 在 PATH；无第三方 Python 依赖。脚本复制源码到临时目录再编译，规避旧版仿真器对中文工程路径的兼容问题；不会修改个人 ModelSim 库映射。

`reports/c1/generated/` 保存 vectors.txt、独立 expected.csv、RTL 实际 actual.csv、编译/仿真日志和 summary.json。输入每行为 id、rst_n、valid、颜色码、RGB十六进制。实际与预期结果每行依次为 id、四组实例各自的 valid/mask。

四组预设阈值分别为 (80,40,40)、(0,0,0)、(255,255,255)、(120,30,90)，覆盖默认规则、极限和不对称差值参数。

`python scripts/run_c1.py --inject-error` 会故意翻转一个期望位，应退出 1；正常测试退出 0。此选项会将本目录报告状态置为失败，应随后正常重跑，或者在独立目录做自检。正常运行本身也执行一次隔离的比较器故意错误自检。

## 本次验收

- 33 个固定锚点：三个颜色轮换，覆盖恰好达到阈值、差 1 不足、负差值、黑白灰。
- 177 个阈值附近样本。
- 固定种子 20261005，每种颜色 4096 个随机 RGB，总计 12288 个。
- 有效信号空拍、运行中复位与恢复、非法颜色；检查输出无 X/Z、输入改变时输出保持、复位异步清零。
- 12636 个输入周期 × 4 个参数实例 = 50544 组 valid/mask 比较，全部一致。
- testbench 的最大模拟时间为 2ms；外部工具每次运行超时 90 秒。编译失败、超时、未完成、数据不匹配均报失败。
- 干净目录独立运行通过；故意错误命令实际退出 1。

Python 判据使用普通整数独立计算，不以 RTL 输出生成答案。没有做整帧 720p 分类；按阶段要求该项在 C2 完成。S0 的 720p 软件测试不能冒充本模块的整帧 RTL 测试。
