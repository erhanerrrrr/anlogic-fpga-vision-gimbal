## 中断与恢复

另用64×48执行完整帧→短半帧复位→完整恢复→采样半帧停顿→复位→恢复→空帧→分散干扰。两段半帧不发布结果；已合法完成的前一帧可先排空流水线。采样停顿期间busy保持，不能因为ROI收齐就报告完整成功。恢复序列中的完整帧仍逐像素核对。

TB同时检查：所有原始分类位及标签、完整滤波光栅和每个掩膜位、公开/调试结果字段、cfg版本、无通知时整包保持、复位、未知值、标定事件和EOF延迟。图片先从实际RTL输出保存，再转换PNG；文件保存按行缓冲，不改变逐像素比较。

## 性能与边界

| 项目 | 本机可确认的结果 / 限制 |
|---|---|
| 输入吞吐 | 合法行内每拍1个有效像素，无反压；不能据此推断实际摄像头fps |
| 滤波EOF延迟 | W+3拍，720p为1283拍 |
| 检测EOF延迟 | W+7拍，720p为1287拍；重复帧无新通知 |
| 标定生成 | 采样帧EOF之后1拍生成完成事件；应用要等待符合条件的新SOF |
| 换算时间 | 1287/f_clk秒；实际板级f_clk未确认，不填硬件微秒数 |
| 来源新帧计数 | 12个显示输入对应11次新观察，不把重复显示算作新帧 |
| 固定相机定位误差 | 待上板、待人工标注 |
| 真实错误有效/漏检/拒判率 | 待实物数据，需保留数量及对应分母 |
| 显示联调/云台闭环 | B显示RTL未提供；H3/H4待完成 |
