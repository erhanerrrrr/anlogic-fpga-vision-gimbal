# C3：面积和原始包围框统计

日期：2026-10-05；接口 c3-draft-1。独立掩膜输入和 RGB→C2→C3 仿真通过；公共接口仍待 A/B 确认。此阶段不计算中心，不判断目标是否可信。

## 实现内容

逐帧统计所有 mask=1 的像素：raw_count、raw_xmin/raw_ymin/raw_xmax/raw_ymax。框包含边界两端，空帧输出 count=0、四边界=0。

统计的是整张掩膜的总体几何范围。两个分散色块会得到一个共同的框，不能将其解释为一个可靠目标；可信度判断在 C6，多目标分离仍是后续增强。

RTL 在 rtl/recognition/mask_frame_stats.v；累计源文件列表为 rtl/recognition/c3_sources.f。综合源文件列表不包含 testbench。

## 接口

| 信号 | 约定 |
|---|---|
| clk、rst_n | 上升沿采样；低有效异步清零，集成时同步释放 |
| mask_valid、mask | 有效掩膜像素；每拍可接收一个，不提供反压 |
| x、y | 默认各 11 位，来自同一掩膜像素的坐标 |
| sof、eof | 与首、末有效像素同拍；本核不需要 EOL |
| source_frame_id | 默认 32 位，SOF 时保存，发布时返回该帧号 |
| raw_strobe | 本拍已锁存一帧原始统计；每个完整 EOF 发布一次 |
| raw_frame_id、raw_count、raw_xmin/raw_ymin/raw_xmax/raw_ymax | 一次性更新并保持至下一完整帧统计或复位 |

raw_strobe 是本阶段的内部统计完成标志，不是 C4 的完整目标结果包，尚无 target_valid、中心、颜色或 cfg_id。

接 C2 时将 mask_valid、mask、mask_x/y、mask_sof/eof、mask_frame_id 一一接入；与 C2 共用时钟和复位，不使用未延迟的 RGB EOF。

## 位宽、初始化和锁存

- COUNT_WIDTH 默认 20 位，最大表示 1048575，覆盖 720p 的 921600 个像素。若改变最大尺寸，必须令宽度至少为 ceil(log2(W×H+1))；不提供计数溢出检测。
- SOF 重新开始一帧统计。空框从 0 开始；遇到本帧第一个 1 时，四个极值同时初始化为该点坐标，避免错误的最小值。
- 组合逻辑先计算“包含当前像素”的 next_count 和 next_bbox；EOF 时锁存这些 next 值。因此末像素即使是全帧唯一目标也会计入。
- 锁存后清空内部累加器，结果寄存器仍保持。下一拍可直接接下一帧 SOF，不要求帧间空白。
- 同拍 SOF+EOF 的 1×1 帧也支持。连续 1×1 帧会使 raw_strobe 连续多个周期为 1，每周期各代表一个完整结果；下游应按电平有效逐拍接收，不能只做上升沿检测。

## 时序与复位

统计核在采样到有效 EOF 的上升沿后发布原始统计，只有一个锁存动作，没有等待计算周期。以同步接收方视角，结果在下一上升沿可采样。不要将这个时序与 C4 尚未实现的 L_result 混同。

测试中同一原始输入的直连统计比 RGB→C2→C3 统计提前恰好一拍，来自 C2 的一个输出寄存级。两条路径的几何结果完全一致。

启动或帧中复位会清空累加器、已锁存结果和 strobe。复位后直到下一有效 SOF 之前的帧尾全部忽略。被中断帧不发布统计。输入停止时不产生额外通知，已发布字段保持。已有 SOF 尚未遇 EOF 又收到新 SOF 时丢弃未完成累加、从新帧重新开始；此次测试重点覆盖复位中断，未对非法协议进行全面故障注入。

合法输入的坐标、SOF/EOF 和帧号由上游保证；本核不校验完整像素数、帧号是否帧内一致，也不识别错误的提前 EOF。

## 实际测试

固定输入及独立答案：tests/fixtures/c3/cases.json。testbench 生成已知二值形状，另用红/黑像素生成同样形状串入 C2；绿色输入单独验证红色规则下应为空。

| 场景 | 预期原始统计 |
|---|---|
| 640×360 内 (100,80)～(140,110) 红矩形 | 1271，框 (100,80,140,110) |
| 矩形后下一帧仅首点为 1 | 1，框 (0,0,0,0) |
| 随后空帧 | 0，框全 0 |
| 720p 仅末点为 1 | 1，框 (1279,719,1279,719) |
| 紧接 720p 全 1 | 921600，框 (0,0,1279,719) |
| 全 1 后空帧 | 0，不保留旧极值或面积 |
| 连续两个 1×1 帧，一个有目标、一个为空 | 各发布一次，字段互不混用 |
| 帧中复位，随后继续输入残余帧尾 | 不发布中断帧统计 |
| 复位后完整 2×2 目标位于右下角 | 4，框 (14,10,15,11) |
| 首末各一个分散目标点 | 2，框 (0,0,15,11)，仅作为原始统计 |
| 红规则下输入全绿帧 | 0，框全 0 |

共 12 个用例，11 个完整帧结果；直连和串接路径各得到 11 条正确统计。帧号包括 0xffffffff→0 回绕。所有有效输出无 X/Z；字段保持、EOF 通知时机、异步复位、连续帧均由 testbench 检查。故意改坏期望面积必须返回失败。

## 如何运行

```powershell
python scripts/run_c3.py
```

需要 Python 3.7+ 和 ModelSim vlib/vlog/vsim 在 PATH，无第三方 Python 库。使用临时目录编译运行，不依赖中文路径或个人绝对路径。每个外部命令超时 300 秒，仿真 watchdog 为 100ms 模拟时间；超时、编译失败、未完成、字段错误均返回非零。

输出在 reports/c3/generated/：

- actual.csv：实际 RTL 原始统计，包含路径、周期、帧号、count 和四边界。
- timing.csv：EOF、复位和结果通知附近的周期记录。
- eof_trace.vcd：720p 末像素、EOF 锁存和紧随其后的新帧附近波形，约 59KB，可用 ModelSim 打开；未记录整段 720p 全波形。
- summary.json、编译/仿真日志、检查器自检和干净目录复跑日志。

已有结果复查：`python scripts/run_c3.py --check-only`。
检查器故意错误自检：`python scripts/run_c3.py --check-only --inject-error`，应退出 1；故意错误不混入正常通过率。
