# H4E之后的分工与逐阶段验收

共同入口：[H4E](../boards/hx1p35a/h4e/README.md)、[统一接口](interfaces/team-contract-v1.md)、[赛题核对](contest-review.md)。现在可以停止继续堆叠H4E识别规则，保留已通过的最大区域算法，转入三人分工。尚无证据要求重写识别算法。

## A：你——集成、硬件、真实新帧与云台

| 顺序 | 实现与交付 | 进入下一步的条件 |
|---|---|---|
| A1 帧身份/监测 | 完整采集帧ID绑定DDR缓存；复位代次、跨域整包、新帧/重复/超时/坏帧计数；按实际接口接缓存异常监测；新诊断bit和约束说明 | 仿真采集慢于显示、重复显示、半帧、停止/恢复、回绕；重复画面不产生新控制观察，故障可计数、可恢复 |
| A2 独立PWM，可与A1并行 | 核对舵机型号、电压、电流、脉宽、位置式/连续旋转；供电共地、接线、每轴中位/方向/保守限位；PWM RTL/TB | 周期/脉宽/更新边界/复位/限幅仿真；轻载单轴小行程实测，用示波器或逻辑分析仪核对波形 |
| A3 假坐标再水平闭环 | 先用左/中/右/无效/重复/超时/跳变结果验证控制，再接C真实结果；死区、方向、限速、软限位 | 新帧与PWM分别通过；真实目标左右偏差趋于减小，中心不抖，失效不追旧位置，恢复确认后再动 |
| A4 垂直再双轴 | 垂直单独验证，再双轴；启停/丢失保持/重获确认/限位状态 | 左右/上下/斜向、静止、消失、重现、停帧、极限、复位全部通过，记录每轴参数 |
| A5 整机性能/压力 | 逐次接入B/C模块；完整工程资源/时序、长期/光照/复位、帧率/延迟/误差测试 | 每项提供方法、样本数、计数起止值、bit哈希；不得用肉眼连续代替无溢出监测 |

不直接从GPIO给舵机供电；电源按型号配置。20ms/1.5ms只是常见参考，未经核实不能作为统一规格。真正视觉闭环必须等A1和C2通过；准备PWM不必等待B完成全部显示模式。

## B：图像处理与显示——不需要先拿板跑官方例程

| 小阶段 | 需要完成的功能 | 仿真验收与交付 |
|---|---|---|
| B0 复现 | 在自己电脑跑共同基线check/unit/pipeline，确认B7与H4E差异 | 命令、工具版本、退出码和PASS摘要；不用重写已通过模块 |
| B1 动态OSD | 从已验收mixer提取框、中心、文字、Logo；接整包快照，保留现有像素行为 | 假结果：四边、越界裁剪、无效清框、帧中到达、ID不匹配、Logo重叠；关键像素/整图差分、同步和延迟检查。交RTL/TB/参考图/差分及资源报告 |
| B2 真实掩膜对齐 | 使用C实际滤波mask；配对RGB/坐标/源ID；再依次接RAW、GRAY、EDGE、MASK | 1280×720、1650×750真实调度；行间空白、跨帧冲刷、复位、输入不足；无串帧，正常FIFO溢出/欠读为零，故障显式报告。给FIFO深度依据和峰值占用 |
| B3 按键模式 | 共用一份同步消抖；帧边界生效，mode随像素；显示活动配置、标定阶段、机械状态 | 实际计数门槛的略短/相等/略长、抖动、长按、释放、SOF同拍请求、连续/非法请求。不能只用缩短到4周期的TB证明默认值 |
| B4 延迟/性能OSD | A给帧率/延迟/错误计数，B负责单位、有效/不可用标记、状态呈现 | 0值、最大值、无效、更新同拍、帧稳定性；图文正确且不遮挡Logo。最后跑真实B+C联合回归 |

B7独立综合曾使用28 ERAM，其中RGB对齐FIFO占23；不能将此数简单与整板45相加当新整机资源。应先报告增量需求、共享策略和实际峰值，不复制整帧缓存凑对齐。每个小阶段一个PR；A复跑并给新bit后才进行板测。

## C：识别与定位——接管H4E，不恢复旧全局框规则

| 小阶段 | 需要完成的功能 | 仿真验收与交付 |
|---|---|---|
| C1 H4E复现/维护 | 运行68个区域案例和13帧链路；理解逐行回收/容量/超时；维护`rtl/recognition/h4e_region_select.v` | 面积/框/中心与独立8邻域参考一致；保留33分支、主目标加33/153/1216小块、区域回收、64/65游程、超时/恢复、SOF打断和空帧。交复现日志与审查记录 |
| C2 新结果封装 | 适配统一结果包，保留来源/epoch/cfg，重复帧去重；有效/无效均发新事件 | 有效、空帧、容量错误、重复/回绕、复位、停帧/恢复、配置变化；交A/B可直接使用的假结果序列、TB与资源变化 |
| C3a 仅采样 | 接中央16×16采样，输出count/sum/min/max/mean；暂不改阈值 | 精确256点、边界、下一新来源帧开始、忙碌请求、复位；交采样RTL/TB/统计参考 |
| C3b 仅生成参数 | 判断标定成功/失败并生成候选值，先保持活动参数 | 红绿蓝、灰色、混色、过暗/过亮、均匀度和限幅边界；失败保留旧值；交参数规则/参考模型 |
| C3c 原子应用 | pending→下一新来源SOF整体应用，cfg递增；识别/采样同一RGB入口 | SOF同拍生成、busy/请求竞争、cfg回绕、在途旧帧、失败保持；先用24/16/16复现H4E，再板上评估标定 |
| C4 真实输入回放 | 建立RGB888回放和人工标注/统计流程，补照明和反光失败场景 | 软件与RTL一致性、真实误报/漏检/拒判/定位误差分别报告并给分母；手机拍屏不是检测入口像素 |

C现有S0–C10已做了许多独立功能，不要求全部重写；重点是适配当前H4E主区域结果、真实输入和统一协议。不得把C10全局框+固定填充率链整体覆盖进已通过H4E。仅在真实失败证据支持时再添加新的识别规则。

## 汇合顺序与共同交付

第一批：A做帧身份与PWM，B做B0/B1，C做C1/C2。第二批：A假坐标/水平，B做B2，C做C3a。第三批：A垂直/双轴，B做B3，C依次做C3b/C3c。第四批：性能/稳定性/光照/真实数据与展示。并行开发不等于同时合入多个未知功能，A一次验证一个增量。

每个PR包含：基线commit、接口profile、源码和显式源列表、TB、独立参考/固定锚点、场景生成器、可复制命令、工具版本、实际退出码/PASS摘要、资源变化、已知限制，以及A可执行的板测步骤和失败时应回传字段。波形截图不能替代自动断言；单模块综合不能替代整板布局布线。

稳定性首轮建议团队自定30分钟（官方未规定具体时长），同时记录FIFO/DDR可观测错误、来源/显示/结果计数和光照切换恢复。验证前先定义每个计数器观测位置；未接监测的项记“未测”，不记0。每阶段冻结源码和已验收bit，保留回退版本。
